# 🌦️ Weather App

A simple weather application built using HTML, CSS, and JavaScript that fetches real-time weather data using an API.

---

## 🚀 Features

- Get real-time weather information  
- Search weather by city name  
- Displays temperature and weather condition  
- Dynamic UI updates  

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  
- API Integration  

---

## 📂 Project Structure

- in file 

---

## 📌 How It Works

- User enters city name  
- App sends request to weather API  
- API returns data  
- Data is displayed on screen
